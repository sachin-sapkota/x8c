# HelloWorldServer

A simple Elixir web server that responds with "Hello World" and the client's IP address.

## Installation

First, you'll need to install Elixir. You can find instructions on the official Elixir website: https://elixir-lang.org/install.html

Once Elixir is installed, you can follow these steps:

1. **Clone the repository:**
   ```sh
   git clone <repository-url>
   cd hello_world_server
   ```

2. **Install dependencies:**
   ```sh
   mix deps.get
   ```

3. **Run the server:**
   ```sh
   mix run --no-halt
   ```

The server will start on port 4000. You can access it by navigating to `http://localhost:4000` in your web browser.
